DIMORA — third-party assets and licences
=========================================

Materials / textures
--------------------
All surface materials in the 3D view (wood floors, marble, vitrified and anti-skid tiles, concrete, sandstone,
painted plaster, brick, grass, glass, fabrics) are PROCEDURAL: they are generated by DIMORA's own WebGL shader
code at run time (see the pattern functions in frontend/js/app.js). No texture image files are bundled, so there is
nothing third-party to license here.

If you later add CC0 texture sets (for example from https://polyhaven.com or https://ambientcg.com), put them in
frontend/assets/textures/<name>/ and list each one below with its source URL and licence (CC0 1.0).

3D models
---------
All furniture, cars, trees and the house itself are built procedurally from boxes, cylinders and spheres in
frontend/js/app.js. No GLB/OBJ model files are bundled.
